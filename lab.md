## 1. Планування

**Мета продукту:** створити простий застосунок, який допомагає студенту зберігати свої навчальні цілі та відстежувати прогрес їх виконання у відсотках.

Користувач повинен мати можливість:

- вказувати та змінювати прогрес виконання кожної цілі у відсотках (0–100%);
- бачити всі свої цілі та їхній прогрес на одному екрані.

## 4. Реалізація (Псевдокод)

Ключова функція — оновлення прогресу цілі у відсотках.

```
function updateProgress(goalId, newPercent):
    goal = goalList.findById(goalId)

    if goal is not found:
        return "Error: Goal not found"

    if newPercent is not a number:
        return "Error: Progress must be a number"

    if newPercent < 0 or newPercent > 100:
        return "Error: Progress must be between 0 and 100"

    goal.progress = newPercent

    if newPercent == 100:
        goal.status = "completed"
    else:
        goal.status = "in progress"

    save(goalList)
    return "Progress updated"
```

**Короткий опис алгоритму:** функція знаходить ціль за її ідентифікатором, перевіряє, що нове значення є числом у діапазоні від 0 до 100, зберігає його в цілі та автоматично позначає ціль як виконану, якщо прогрес досяг 100%.
